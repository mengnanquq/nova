# 界面重设计：Netflix 视觉体系

替代原 `ui-architecture.md` 的视觉部分（**数据流、视图模型、接缝不变**）。目标是 Netflix 的观感：
纯黑底、billboard hero、横向大行、悬浮/聚焦放大卡片、极简顶栏。

## 1. 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#000000` | 全局底色（Netflix 是纯黑，不是深灰） |
| `surface` | `#141414` | 顶栏实底、菜单 |
| `surface-hover` | `#1F1F1F` | 卡片/按钮悬停 |
| `text` | `#FFFFFF` | 主文字 |
| `text-secondary` | `#B3B3B3` | 元信息 |
| `text-muted` | `#808080` | 次要说明 |
| `accent` | `#E50914` | 品牌红：只用于 logo 点、选中态、进度条，**不要大面积铺** |
| `btn-primary-bg` | `#FFFFFF` | 主按钮底（播放） |
| `btn-primary-fg` | `#000000` | 主按钮字 |
| `btn-secondary-bg` | `#FFFFFF26` | 次按钮底（更多信息） |
| `scrim-bottom` | `#00000000 → #000000E6` | hero 底部渐变 |

## 2. 顶栏

- 高 72px（Netflix header 实测 `height: 72px`），**未滚动时用顶部黑→底部透明的压暗渐变浮在 hero 上**
  （实测 `linear-gradient(to top, rgba(0,0,0,0) 0%, rgb(0,0,0) 100%)`，我们另向下多淡出 56px）；
  页面滚动超过 40px 后渐变为 `surface` 实底（180ms）。
- 左：`NOVA` 字标（红色圆点 + 白色字），字重 bold、字距 -0.5。
- 中：库标签——无胶囊、无下划线，只有 **当前项白色 + 其余 `text-secondary`**，间距 24px；溢出用右缘渐隐（已有）。
- 右：搜索图标按钮（聚焦时展开为输入框，宽 240px）、用户圆形头像。
- 悬停/聚焦项：白色，不加背景块。

## 3. Home：Billboard + 行

**Billboard（首屏 88vh，最大 720px）**

- 全宽 backdrop（`Image` 铺满、`clip: true`），底部 `scrim-bottom` 渐变，左侧再加一层 `#000000 → transparent` 的横向渐变保证文字可读。
- 内容左对齐，左留白 60px，垂直居下 22%：
  - 标题：48px bold（有条目 logo 用 logo 图，高度 64–96px）
  - 元信息行：`2024 · 电影 · 2 小时 46 分 · 4K HDR`，14px `text-secondary`
  - 简介：最多 3 行，16px，宽 560px
  - 按钮行：`▶ 播放`（白底黑字，130×44，圆角 4）、`ⓘ 更多信息`（`btn-secondary-bg`，150×44）
- 右下角：`4K`/`HDR` 小徽标（描边胶囊，12px）。

**行（Row）**

- 行标题：22px bold，左留白 60px，右侧 `查看全部 ›`（14px，`text-secondary`，悬停变白）。
  聚合行（「继续观看」「最近添加」，没有对应媒体库）不显示「查看全部 ›」——没有可去的库页，就不留这个入口。
- 行间距 40px；首行距 billboard 底 24px。
- 卡片：默认宽 260px（16:9 用 320px），2:3 用于"最近添加"，1:1 用于"继续观看"封面（Netflix 用 16:9 缩略图）。
- 卡片结构（官方）：**海报在上、标题在卡片下方**（14px/400 白字、单行省略、行高 21px、上距 4px；≥1920 档 16px / 24px / 8px，标题块高 32px）。
- **聚焦/悬停放大**：官方 `scale 1.05`、`transition: transform 0.2s ease-in-out`、延迟 400ms；`z-index` 提升（Slint 用后画的兄弟覆盖层，布局零跳动），**没有**悬停信息面板、也不上移。
- 放大余量按官方 `li` padding 反推（左右 6px、上下 10.4px）：覆盖层每边只溢出 6px / 10px，卡间距与标题下距 12px 兜住，所以放大卡不会盖住行标题。
- 进度条：高 3px，`accent` 填充，位置在卡片底部内侧，左右各 8px 内边距。
- 行滚动：横向 `Flickable`，`interactive: true`，滚轮/拖拽；左右各一层 60px 渐隐（已有实现复用）。

## 4. Library 页

- 顶部标题 34px bold，左留白 60px，下面一行 14px `text-secondary`（"200 部"）。
- 右上：排序下拉（保持现有）。
- 网格：6 列（宽 ≥1440 用 7 列），卡片 2:3，间距 12px，无边框、无阴影。
- 卡片同 Home：卡下标题 + 悬停 `scale 1.05`（官方结构，没有信息面板）。

## 5. Detail 页

- 全宽 backdrop（高 78vh，实测 845/1080）+ 上下双向渐变到页底（页底 `#0F0F0F`）。
- **内容块（标题 / 原文名 / 元信息 / 简介 / 按钮 / 版本下拉）叠在 hero 下半部**：一个纵向布局，
  底端锚定在 hero 下缘上方 112px（官方实测），顶端由自身高度反推（1920 官方顶端在 hero 的 34.7%）。
  子项一律不写 `y`，位置只靠顺序 + `spacing`；分块各自绝对定位会互相重叠（踩过）。
- 标题 48px bold（高度自适应，长标题可换行不裁切）；元信息行 14px/500；类型标签用 `text-secondary` 加 `·` 分隔（**不要胶囊**）。
- 简介宽 697px，16px，不限行数。详见 `docs/ui-netflix-1to1.md` 第 7 节的实测表。
- 按钮行：`▶ 播放` / `+ 我的列表`（次要按钮，点击先只做视觉态）。
- 版本选择：一行 `NETFLIX` 风格的下拉（"播放版本：4K HDR · 简体中文 ▾"），展开是 `surface` 面板、选中项左侧 3px `accent`。

## 6. 播放器

保持现有控制层结构（已对标 Infuse 那套），只换配色：遮罩渐变加深、进度条改 `accent` 红；
圆形图标钮用 Netflix 实测样式（40×40、`rgba(22,22,22,.7)` 底、`1px rgba(128,128,128,.7)` 描边、图标 24px），
进度条悬停 / 拖动时轨道变粗、拖动头放大 1.2 倍。

## 7. 动效

只有三种，时长一律 180–200ms、`ease-out`：
1. 顶栏滚动变实底
2. 卡片聚焦放大（`scale 1.05`，标题常驻卡下，不浮出面板）
3. 页面切换淡入（opacity 0→1，150ms）

**禁止**：渐变球、发光边框、玻璃拟态、无意义的视差。

## 8. 搜索页

搜索是**独立结果页**（`Route::Search { term }`），不再"就地过滤首页"。

- 页内不画顶栏：顶部 `navbar-height`(72px) 之下留 40px，放一个大搜索框
  （高 48px、字号 22px、透明底 + 底部 1px `hairline`，右侧清空按钮）。
  顶栏的搜索框与页内大搜索框走同一条链路：第一次输入就切到搜索页，
  焦点自动落到大搜索框。
- 结果头：`「{term}」的搜索结果` + `共 {total} 部`（22px bold + 12px `text-muted`，
  与媒体库标题行同构）。
- 结果网格：**与媒体库同一个组件** `ui/poster_grid.slint`（6 列、`content-gutter`、
  `card-gap` 12px、5:7 竖版卡、`radius-poster`、放大覆盖层）。网格数学只有一份。
- 只收电影 / 剧集：集（Episode）与季（Season）属于详情页的选集层级，不进搜索结果。
- 四态：`Idle`（空输入）/ `Loading`（"搜索中…"，不转圈）/ `Ready` / `Empty`
  （"没有找到相关内容" / "换个关键词试试"）/ `Error`（错误文案 + 重试）。
- 交互：输入时先用本地缓存立即出结果，停手 300ms 后打服务端（防抖 + 代次丢弃过期结果）；
  `Enter` 立即提交并把焦点还给全局键盘（方向键导航网格）；`Esc` 清空并回首页；
  点结果卡走现有 `open_detail`。
- 放大覆盖层的上边界是结果头下沿（不是顶栏），避免放大态盖住结果头。

> Netflix 搜索页本身**未能实测**（`/search`、`/browse` 未登录一律 302 回登录页，
> archive.org 只有 301/302 快照）。本节按其公开行为推导，逐条标注见
> `docs/ui-netflix-1to1.md` 第 8 节。

## 9. 验收

- 无头快照（testing backend）与**窗口自截**（`--screenshot --screenshot-delay 8000`）两套都要出图，
  真实数据（已登录的 Emby）下检查：billboard、两行卡片、放大态、搜索页（结果 / 空态）、详情页。
- 卡片放大不得引起布局跳动（用绝对定位/覆盖层，不参与行布局计算）。
- 中文无豆腐块；对比度 ≥4.5:1（`text-secondary` 在 `#000` 上为 8.9:1，合格）。
